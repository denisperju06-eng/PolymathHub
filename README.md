## 🌟 Despre Proiect

**PolymathHub** este o platformă web de învățare activă, proiectată după principiile științei cognitive moderne: **repetiție spațiată (Spaced Repetition)**, **rechemare activă (Active Recall)** și **gamificare structurală**. Aplicația reunește sub aceeași cupolă două mari domenii de cunoaștere: **Informatică & Programare de Nivel Înalt** și **Limbi Străine & Comunicare Internațională**.

Aplicația este construită pe o arhitectură **Single Page Application (SPA)** de înaltă performanță, utilizând tehnologii web native (Vanilla JavaScript ES2024, CSS3 modern cu variabile CSS dinamice și HTML5 semantic), fără dependințe greoaie de runtime, oferind timp de încărcare sub 50ms și funcționare completă **offline / Local-First**.

## ⚡ Caracteristici Tehnice & Arhitectură

### 1. Cele 3 Moduri Interactive de Practică
Fiecare capitol din cele 470+ conține 3 moduri complementare de antrenament:
* **✍️ Modul Scriere (Code & Translation Editor):**
  * Editor cu font monospace `JetBrains Mono` și indentare inteligentă la `Tab`.
  * Motor de evaluare tolerant la spații albe și convenții de formatare prin **expresii regulate robuste (Regex)**.
  * Sistem de asistență graduală: **Indiciu (Hint)**, **Model Asemănător (Parallel Example)** și **Soluție Oficială Asistată**.
* **🔄 Modul Potrivire Perechi (Matching Pairs Engine):**
  * Mecanism vizual pe 2 coloane pentru fixarea rapidă a vocabularului sau a sintaxei.
  * Feedback tactil și cromatic instantaneu: selecție activă, eroare discretă cu resetare automată și animare de succes la conectarea corectă.
* **❓ Modul Quiz Grilă (Knowledge Check):**
  * Întrebări concepute pentru a elimina capcanele frecvente de înțelegere conceptuală.
  * Răspuns explicativ detaliat afișat imediat după validare.

---

### 2. Gamificare & Știința Învățării
* **🔥 Daily Streak Inteligent:**
  * Calcul calendaristic local bazat pe fusul orar al utilizatorului (`YYYY-MM-DD`).
  * Sistem de protecție împotriva trișării: contorizează doar rezolvările autonome. Dacă utilizatorul a copiat soluția oficială, exercițiul este marcat ca *asistat (50/50)* și nu inflaționează streak-ul.
* **⭐ Sistem de Măiestrie (Mastery 3 Stele ★★★):**
  * Fiecare rezolvare repetată sporește nivelul de stăpânire al conceptului de la *Neînceput* &rarr; *În Învățare (★)* &rarr; *Consolidat (★★)* &rarr; *Stăpânit / Mastered (★★★)*.
* **📅 Heatmap de Activitate pe 28 de Zile:**
  * Reprezentare vizuală a ritmului zilnic de studiu inspirată din graficul de contribuții GitHub.
* **🏆 Sistemul celor 5 Ligi Competitive:**
  * Progresie automată pe baza XP-ului total acumulat:
    * 🥉 **Liga de Bronz** (0 – 199 XP)
    * 🥈 **Liga de Argint** (200 – 499 XP)
    * 🥇 **Liga de Aur** (500 – 999 XP)
    * 💎 **Liga de Platină** (1.000 – 1.999 XP)
    * 👑 **Liga de Diamant** (2.000+ XP)
* **🎉 Efecte Vizuale Discrete:** Motor nativ de confeti pe canvas HTML5, activat exclusiv la atingerea țintei zilnice sau completarea unui nivel.

---

### 3. Teme Vizuale Ultra-Polisate (WCAG AAA Contrast)
Interfața pune la dispoziție **7 palete cromatice** optimizate matematic pentru lizibilitate maximă și confort optic pe sesiuni lungi de studiu:
1. 🌲 **Emerald Forest (Default):** Temă întunecată nobilă bazată pe tonuri profunde de smarald și mentă luminoasă.
2. 🌌 **Cyber Dark:** Estetică modernă inspirată de WebStorm / VS Code în tonuri de ardezie și indigo vibrant.
3. 📜 **Sepia Book:** Mod cald de lectură pe fundal crem natural, cu font serif `Merriweather` și contrast optimizat pentru ochi obosiți.
4. 🔮 **Neon Amethyst:** Paletă violet-ametist radiantă cu accente luminoase de liliac.
5. 🌅 **Sunset Amber:** Nuanțe calde de ambră aurie și cărbune ars.
6. 🌊 **Ocean Deep:** Tonuri marine de safir marin și cian ceresc.
7. ☀️ **Daylight Clean:** Temă deschisă ultra-clară cu fundal alb pur și text albastru-marin de contrast înalt (> 14:1 contrast ratio).

---

### 4. Navigație SPA Fluentă & Buzunar Off-Canvas
* **Navigație pe 5 Pagini SPA:**
  * `Catalog` &mdash; Prezentarea generală a disciplinelor, nivelurilor și gradului de completare.
  * `Studiu` &mdash; Laboratorul de lectură, teorie, dicționar integrat și exerciții interactive.
  * `Activitate` &mdash; Heatmap pe 28 de zile, calendar, statistici de performanță și distribuție XP.
  * `Ligi` &mdash; Clasament gamificat și statutul diviziei curente.
  * `Profil & Setări` &mdash; Personalizare utilizator, alegere temă, țintă zilnică și export/import stare.
* **Buzunar Off-Canvas (Pocket Drawer):** Panou lateral glisant ce permite comutarea instantanee între oricare dintre cele 470+ de capitole fără a părăsi laboratorul de studiu.

---

### 5. Arhitectură Local-First & Securitate
* Toate datele (XP, Streak, Progres capitole, Teme, Nume utilizator) sunt salvate instantaneu în `window.localStorage`.
* **Zero Backend & Zero Dependențe Externe:** Datele nu părăsesc niciodată dispozitivul utilizatorului.
* **Zero Trackere sau Cookie-uri intrusive:** Respect absolut pentru confidențialitate și viteză.

## 🚀 Rulare Locală & Dezvoltare

Aplicația rulează nativ în orice browser modern fără a necesita procese de build (`npm run build`), webpack sau bundlere:

### Pasul 1: Clonare Repository
```bash
git clone https://github.com/denisperju06-eng/PolymathHub.git
cd PolymathHub
```

### Pasul 2: Lansare Server Local
Poți lansa aplicația folosind orice server HTTP static simplu:

* **Cu Python 3:**
  ```bash
  python3 -m http.server 8000
  ```
* **Sau cu Node.js (`npx serve`):**
  ```bash
  npx serve .
  ```
* **Sau cu extensia Live Server din VS Code / WebStorm.**

### Pasul 3: Deschide în Browser
Navighează la adresa:
```
http://localhost:8000
```
