# PolymathHub (Polymath Studio)

Platformă interactivă de învățare și practică activă pentru SQL, Java, JavaScript și Engleză C1, echipată cu sistem de streak zilnic, calcul de XP, sistem de ranguri și validare automată.

## Caracteristici

- **Module & Discipline**:
  - 🗄️ **SQL**: De la SELECT, WHERE, JOIN până la tranzacții și optimizări.
  - ☕ **Java**: Fundamente, OOP, structuri de date, colecții și streams.
  - 🟨 **JavaScript**: Sintaxă modernă ES6+, asincronism, Promises și manipulare DOM.
  - 🇬🇧 **Engleză C1**: Vocabular avansat, expresii idiomatice și exerciții de traducere contextuală.
- **Filtrare Avansată**: Filtrează lecțiile după nivel de senioritate (Începător → Exemplar) sau caută prin cuvinte cheie.
- **Sistem de Mastery (★★★)**: Obține până la 3 stele per exercițiu prin practică repetată.
- **Gamification**: Streak zilnic, niveluri XP, heatmap de activitate pe 28 de zile.
- **Teme Vizuale**: Cyber Indigo, Emerald Zen, Sunset Amber, Daylight Studio.
- **Local First**: Salvare automată a progresului în `localStorage`.
